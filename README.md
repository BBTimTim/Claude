# Claude Code – útmutató kezdőknek

Egyoldalas, magyar nyelvű weboldal a Claude Code használatáról, teljesen kezdőknek, példákkal.

## Tartalom

Bevezető, szószedet, környezetek (web, terminál, VS Code, Desktop), első lépések, parancsok, `@` és `#`, `CLAUDE.md` és memória, bővítések (skill, agent), hookok, beállítások, biztonság, MCP, plugin, összefoglalás.

## Megnyitás

Nincs szükség telepítésre: nyisd meg az `index.html` fájlt a böngészőben.

## Fájlok

- `index.html` – a weboldal tartalma (Bootstrap 5)
- `style.css` – saját stílusok
